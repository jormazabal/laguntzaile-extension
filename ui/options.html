Información

🔒 Privacidad

Tu API Key se guarda localmente en tu navegador y nunca se envía a ningún servidor excepto OpenAI.

Cuando usas "Leer" o "Explicar", se envía una captura de la pestaña visible a la API de OpenAI para su análisis.

🔊 Voz generada por IA

El audio de lectura es generado mediante OpenAI TTS (Text-to-Speech). La voz no es humana, es sintética generada por inteligencia artificial.

💡 Cómo usar

  1. Navega a una página con un ejercicio o contenido educativo
  2. Haz clic en el icono de Laguntzaile
  3. Leer: Lee en voz alta el texto seleccionado o el enunciado principal
  4. Explicar: Genera una explicación sencilla y la lee en voz alta

🔒 Política de Privacidad

Laguntzaile - Última actualización: Diciembre 2024

1. Información que procesamos

Laguntzaile procesa los siguientes datos cuando usas las funciones "Leer" o "Explicar":

  • Captura de pantalla: Una imagen de la pestaña visible en tu navegador.
  • Texto generado: El texto extraído o la explicación generada por la IA.
  • Audio generado: La conversión del texto a voz (TTS).

⚠️ Importante: La captura de pantalla puede contener datos personales si están visibles en la página web.

2. Qué NO almacenamos

  • No almacenamos capturas de pantalla en ningún servidor propio.
  • No guardamos el texto ni el audio generado después de su uso.
  • No mantenemos historial de tus consultas.
  • No recopilamos datos de navegación ni actividad.

3. Dónde se procesan los datos

Los datos se envían a OpenAI (api.openai.com) para:

  • Analizar la captura de pantalla y extraer/explicar el contenido (API de Visión).
  • Convertir el texto en audio (API de Text-to-Speech).

OpenAI tiene su propia política de privacidad.

4. Tu API Key

  • Tu API Key de OpenAI se guarda localmente en tu navegador.
  • Nunca se comparte con terceros excepto para autenticar las llamadas a OpenAI.
  • Puedes eliminarla en cualquier momento desde la página de opciones.

5. Seguridad

  • Toda la comunicación con OpenAI se realiza mediante HTTPS.
  • Las llamadas a la API incluyen store: false para que OpenAI no almacene los datos.
  • No ejecutamos código remoto ni cargamos scripts externos.

6. Finalidad

La única finalidad de Laguntzaile es ayudar a leer y explicar contenido educativo, especialmente para estudiantes con dificultades de aprendizaje como dislexia o TEL.

7. Publicidad y venta de datos

  • No mostramos publicidad.
  • No vendemos ni compartimos tus datos con terceros.
  • No utilizamos los datos para crear perfiles de usuario.

8. Tus derechos

  • Puedes revocar el consentimiento en cualquier momento desde la extensión.
  • Puedes eliminar todos los datos locales desinstalando la extensión.

9. Contacto

Si tienes preguntas sobre esta política de privacidad:

1. Information we process

Laguntzaile processes the following data when you use the "Read" or "Explain" functions:

  • Screenshot: An image of the visible tab in your browser.
  • Generated text: The extracted text or AI-generated explanation.
  • Generated audio: The text-to-speech (TTS) conversion.

⚠️ Important: The screenshot may contain personal data if visible on the webpage.

2. What we do NOT store

  • We do not store screenshots on any server.
  • We do not save the generated text or audio after use.
  • We do not keep a history of your queries.
  • We do not collect browsing data or activity.

3. Where data is processed

Data is sent to OpenAI (api.openai.com) to:

  • Analyze the screenshot and extract/explain content (Vision API).
  • Convert text to audio (Text-to-Speech API).

OpenAI has its own privacy policy.

4. Your API Key

  • Your OpenAI API Key is stored locally in your browser.
  • It is never shared with third parties except to authenticate OpenAI calls.
  • You can delete it anytime from the options page.

5. Security

  • All communication with OpenAI uses HTTPS.
  • API calls include store: false so OpenAI does not retain data.
  • We do not execute remote code or load external scripts.

6. Purpose

Laguntzaile's sole purpose is to help read and explain educational content, especially for students with learning difficulties like dyslexia or language impairment.

7. Advertising and data sales

  • We do not show advertising.
  • We do not sell or share your data with third parties.
  • We do not use data to create user profiles.

8. Your rights

  • You can revoke consent anytime from the extension.
  • You can delete all local data by uninstalling the extension.

9. Contact

1. Prozesatzen dugun informazioa

Laguntzailek datu hauek prozesatzen ditu "Irakurri" edo "Azaldu" funtzioak erabiltzen dituzunean:

  • Pantaila-argazkia: Zure nabigatzailean ikusgai dagoen fitxaren irudia.
  • Sortutako testua: Ateratako testua edo IAk sortutako azalpena.
  • Sortutako audioa: Testutik ahotsera (TTS) bihurketa.

⚠️ Garrantzitsua: Pantaila-argazkiak datu pertsonalak izan ditzake web orrian ikusgai badaude.

2. Zer EZ dugu gordetzen

  • Ez ditugu pantaila-argazkiak inongo zerbitzarian gordetzen.
  • Ez dugu sortutako testua edo audioa gordetzen erabili ondoren.
  • Ez dugu zure kontsulten historiala mantentzen.
  • Ez ditugu nabigazio-datuak edo jarduera biltzen.

3. Non prozesatzen diren datuak

Datuak OpenAI-ra (api.openai.com) bidaltzen dira:

  • Pantaila-argazkia aztertu eta edukia atera/azaltzeko (Vision API).
  • Testua audiora bihurtzeko (Text-to-Speech API).

OpenAI-k bere pribatutasun-politika du.

4. Zure API Gakoa

  • Zure OpenAI API Gakoa lokalean gordetzen da zure nabigatzailean.
  • Ez da inoiz hirugarrenekin partekatzen, OpenAI deiak autentifikatzeko izan ezik.
  • Edozein unetan ezaba dezakezu aukeren orrialdetik.

5. Segurtasuna

  • OpenAI-rekin komunikazio guztia HTTPS bidez egiten da.
  • API deiek store: false dute OpenAI-k datuak ez gordetzeko.
  • Ez dugu urruneko koderik exekutatzen ez kanpoko scriptak kargatzen.

6. Helburua

Laguntzaileren helburu bakarra hezkuntza-edukia irakurtzen eta azaltzen laguntzea da, batez ere ikaskuntza-zailtasunak dituzten ikasleentzat, hala nola dislexia edo hizkuntza-nahasmendua.

7. Publizitatea eta datuen salmenta

  • Ez dugu publizitaterik erakusten.
  • Ez ditugu zure datuak saltzen edo partekatzen hirugarrenekin.
  • Ez ditugu datuak erabiltzaile-profilak sortzeko erabiltzen.

8. Zure eskubideak

  • Baimena edozein unetan ken dezakezu luzapenetik.
  • Datu lokal guztiak ezaba ditzakezu luzapena desinstalatuz.

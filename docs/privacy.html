🔒 Política de Privacidad

Extensión Laguntzaile - Última actualización: Diciembre 2024

1. Información que procesamos

Laguntzaile procesa los siguientes datos cuando usas las funciones "Leer" o "Explicar":

  • Captura de pantalla: Una imagen de la pestaña visible en tu navegador.
  • Texto generado: El texto extraído o la explicación generada por la IA.
  • Audio generado: La conversión del texto a voz (TTS).
⚠️ Importante: La captura de pantalla puede contener datos personales si están visibles en la página web que estás viendo.

2. Qué NO almacenamos

  • No almacenamos capturas de pantalla en ningún servidor propio.
  • No guardamos el texto ni el audio generado después de su uso.
  • No mantenemos historial de tus consultas.
  • No recopilamos datos de navegación ni actividad.

3. Dónde se procesan los datos

Los datos se envían a OpenAI (api.openai.com) para:

  • Analizar la captura de pantalla y extraer/explicar el contenido (API de Visión).
  • Convertir el texto en audio (API de Text-to-Speech).

OpenAI tiene su propia política de privacidad que aplica al procesamiento de estos datos.

4. Tu API Key

  • Tu API Key de OpenAI se guarda localmente en el almacenamiento de tu navegador.
  • Nunca se comparte con terceros excepto para autenticar las llamadas a OpenAI.
  • Puedes eliminarla en cualquier momento desde la página de opciones.

5. Seguridad

  • Toda la comunicación con OpenAI se realiza mediante HTTPS (conexión cifrada).
  • Las llamadas a la API incluyen store: false para indicar a OpenAI que no almacene los datos.
  • No ejecutamos código remoto ni cargamos scripts externos.

6. Finalidad

La única finalidad de Laguntzaile es ayudar a leer y explicar contenido educativo visible en pantalla, especialmente para estudiantes con dificultades de aprendizaje como dislexia o TEL.

7. Publicidad y venta de datos

  • No mostramos publicidad.
  • No vendemos ni compartimos tus datos con terceros para fines comerciales.
  • No utilizamos los datos para crear perfiles de usuario.

8. Tus derechos

  • Puedes revocar el consentimiento en cualquier momento desde la extensión.
  • Puedes eliminar tu API Key y todos los datos locales desinstalando la extensión.
